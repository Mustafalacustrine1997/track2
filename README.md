## 🤖 What Is track2?

RoboWorld Competition Track 2 focuses on embodied navigation. "Embodied" simply means the intelligence has a body — a physical or simulated agent that exists in a space rather than sitting in a spreadsheet. Instead of answering questions about the world, an embodied system has to move through it: find a doorway, avoid an obstacle, approach a person politely, reach a destination.

The toolkit bundles the pieces that make this possible. Vision-language components let the software connect what a camera sees with written or spoken descriptions. World modeling components let it build an internal picture of a space and predict what happens next. Navigation components turn those predictions into movement. Together they form a complete loop: look, understand, decide, move, and look again.

Because this is the official toolkit for the track, the way it behaves matches the way the competition is judged. Practising with it means practising with the same building blocks the event is built on.

## ✨ Key Features

- Social navigation: the toolkit treats people as part of the environment, not as furniture. Paths are planned with awareness of where humans are and where they are likely to go.
- Vision-language understanding: connect what is seen to what is described, so a plain-language destination can guide movement.
- World modeling: build and refine an internal model of a space so the system can anticipate obstacles and openings before reaching them.
- Visual navigation: move toward goals using camera input alone, without needing a perfect map handed to you in advance.
- Embodied intelligence workflows: a complete loop from perception to action, ready to inspect and experiment with.
- Competition alignment: designed around RoboWorld 2026 Track 2, so your practice matches the event.
- Beginner-accessible interface: no code editing required to open the toolkit and start exploring scenarios.
